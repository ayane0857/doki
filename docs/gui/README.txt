土器体積推定 GUI版 - 使い方
===========================

PotteryVolume_gui.exe を起動します。実行先PCにPythonを入れる必要はありません。
PotteryVolume_gui.exe と _internal フォルダーは同じフォルダーに置いてください。
タイトルバーにはビルドされたバージョンが表示されます。

■ 更新を確認する

起動時にバックグラウンドで更新を確認します。新版がある場合は通知が表示され、
「今すぐ更新」「後で」「この版をスキップ」を選べます。更新中は進捗が表示され、
ダウンロードはキャンセルできます。ネットワークに接続できない場合、起動時は
通知を出さずにログへ記録します。

「表示」メニューの「更新を確認…」から手動確認できます。
「起動時に更新を確認する」で自動確認のオン・オフを切り替えられます。

■ 1. 土器画像を選ぶ

「土器実測図」欄で画像を選ぶか、土器実測図をウィンドウへドラッグ＆ドロップします。
対応形式は PNG、JPEG、BMP、TIFF です。

■ 2. スケールを設定する

「指定方法」から、分かっている情報に合う方法を選びます。

・mm/px を直接指定: 図面の1ピクセル当たりの実寸が分かる場合
・スケール線の px と mm: スケール線の画像上の長さと実寸が分かる場合
・2点座標と既知 mm: 既知の長さの両端を画像上で指定する場合
・器高から換算: 土器の器高の実寸が分かる場合
・px（スケール未指定）: 実寸を指定しない場合。結果はpx単位になります。

目盛り画像を使う場合は「目盛り画像」欄に画像を指定し、「画像から自動設定…」を押します。
土器画像と目盛り画像を同時にウィンドウへドロップして選ぶこともできます。
候補が不確かな場合は「目盛りを確認・手動修正…」で線の位置と実寸を確認してください。

■ 3. 計算して結果を確認する

「体積・容量を計算する (Enter)」を押します。推定結果と注意メッセージが表示されます。
輪郭や回転軸が不自然な場合は「詳細設定」で回転軸 x や切り出し範囲を調整し、再計算します。
デバッグ出力先を指定すると、検出結果を画像で確認できます。

計算後は「輪郭を手動補正」から内面・外面の半径を調整し、「補正して再計算」を押せます。

■ 4. 結果をコピーする

「TSV行をコピー」「見出し付きTSV行」「縦テーブルをコピー」などを押してから、
Excel等のアプリで Ctrl+V を押します。

「測定履歴」ではセルを選択して Ctrl+C でコピーできます。選択セルの内容は Delete または
Backspace で消去できます。

■ 注意

このツールは土器断面を回転対称と仮定して体積を推定します。画像の状態や検出結果を確認し、
必要に応じてスケールや輪郭を手動で補正してください。

ライセンス情報は同じフォルダーの THIRD_PARTY_LICENSES.txt、またはアプリ内の
「ライセンス表記」から確認できます。
